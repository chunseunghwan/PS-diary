# 표현 가능한 이진트리 (Programmers 150367)

## 문제 링크
https://school.programmers.co.kr/learn/courses/30/lessons/150367

## 1차 풀이 — 재귀를 이용한 접근

### 문제의 핵심 조건

문제에서는 다음과 같이 가정합니다.

> 이진트리에서 리프 노드가 아닌 노드는 자신의 왼쪽 자식이 루트인 서브트리의 노드들보다 오른쪽에 있으며, 자신의 오른쪽 자식이 루트인 서브트리의 노드들보다 왼쪽에 있다고 가정합니다.

이걸 뒤집어서 생각하면, 결국 확인해야 하는 것은 **"자식 노드가 존재하면 그 부모 노드도 존재해야 한다"**는 조건입니다. 즉

child == 1 => parent == 1

이 성립하지 않는 경우, 다시 말해 **부모가 0(존재하지 않음)인데 그 서브트리 안에 1(존재하는 노드)이 있는 경우**를 찾아내면 그 트리는 표현 불가능한 트리가 됩니다.

### 왜 포화 이진트리 모양으로 만드는가

주어진 수를 그대로 이진수로 바꾸기만 하면, 각 자리의 비트가 트리의 어느 노드에 대응하는지에 대한 규칙이 없습니다. 규칙을 만들기 위해 이진수를 **포화 이진트리(complete/perfect binary tree)** 모양의 배열로 맞춰줍니다. 포화 이진트리 형태로 맞추면, "배열의 정중앙 = 루트, 왼쪽 절반 = 왼쪽 서브트리, 오른쪽 절반 = 오른쪽 서브트리"라는 일관된 규칙이 생깁니다.

### 포화 이진트리의 노드 개수 유도

트리의 높이를 0부터 시작한다고 하면,

| 높이 | 노드 개수 | 비고 |
|---|---|---|
| 0 | 1 | 시작 |
| 1 | 2 | 이전 높이 노드 수 × 2 |
| 2 | 4 | 이전 높이 노드 수 × 2 |
| ... | ... | ... |

즉 전체 노드 수는

1 + (1×2) + (2×2) + (2×4) + ...

형태의 등비수열이 되고, 이를 정리하면 높이 `n`짜리 포화 이진트리의 전체 노드 개수는

2^(n+1) - 1

이 됩니다. 그래서 주어진 수의 이진수 길이를 이 값 이상으로 맞추기 위해, **가장 작은 `2^k - 1` 크기**로 배열을 잡고 앞을 0으로 채웁니다.

### 재귀 규칙 — root 인덱스

배열의 시작 인덱스를 `start`, 끝 인덱스를 `end`라고 하면

root = (start + end) / 2

가 현재 구간의 루트가 됩니다. 이 규칙을 이용해 구간을 절반씩 나누며 재귀적으로 내려갈 수 있습니다.

### 판별 로직

- 루트(현재 구간의 중앙)가 `1`이면: 왼쪽 구간과 오른쪽 구간으로 나눠 각각 재귀적으로 검사한다.
- 루트가 `0`이면: 그 구간(서브트리) 안에 `1`이 하나라도 있으면 표현 불가능 → `false`.

### 예시

아래와 같은 형태의 트리가 있다고 가정합니다.

              1
        x          y
     z    h     i    j
    1 0  0 0   1 1  0 1


1. 높이 0의 노드(루트)가 `1`인지 확인하고, 다음 높이로 내려간다.



              
        x             y
     z      h      i     j
    1 0    0 0    1 1   0 1 

2. 구간이 `x`가 루트인 트리와 `y`가 루트인 트리로 나뉜다. 이때 `x`나 `y`가 `0`인데 그 서브트리 안에 `1`이 하나라도 있으면 `false`.




     z      h      i     j
    1 0    0 0    1 1   0 1


3. 다시 구간이 나뉘고, 같은 방식으로 각 구간에 `1`이 존재하는지 확인하는 과정을 리프까지 반복한다.

이 과정을 재귀로 구현하면 전체 문제를 풀 수 있습니다.
